# Генериране на инсталационен ZIP

Изпълнете от основната папка на модула:

```sh
php scripts/build-zip.php
```

Необходими са PHP 8.1+ и разширението `zip` (`ZipArchive`).

Скриптът чете `$this->version` от `creditjet.php` и създава
`dist/CC_PrestaShop_9_JET_v.<версия>.zip` с основна папка `creditjet/`.
При версия `2.0.2` името е `CC_PrestaShop_9_JET_v.2.0.2.zip`.
Архивът със същото име се заменя, а старите архиви в `dist`, съответстващи
на `CC_PrestaShop_9_JET_v.*.zip`, се изтриват след успешно генериране.

Пакетът включва кода, ресурсите, преводите, документацията и `sbom.json`.
Не включва `vendor` (зависимостите са само за разработка), Git, локални
настройки, инструменти за разработка, скрипта за пакетиране и самата `dist`.
